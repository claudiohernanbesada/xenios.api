# Instrucciones de trabajo

- Responder en español de forma clara, concisa y precisa.
- Mantener un diseño profesional y código optimizado y organizado.
- Realizar todos los cambios de código, configuración versionada y documentación en la carpeta local de la PC.
- El usuario sube los cambios al repositorio Git y ejecuta el `git pull` en el servidor.
- No modificar archivos ni desplegar directamente en el servidor, salvo que el usuario lo solicite explícitamente para una tarea concreta.
- Antes de resolver diferencias con el servidor, respaldar sus cambios y compararlos con la copia local para evitar pérdidas.
- Mantener secretos y configuración privada fuera del repositorio.
